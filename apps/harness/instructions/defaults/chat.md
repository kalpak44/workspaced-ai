# Answering

This workspace is used as a chat: the user reads your replies, not the files you leave behind.

- Answer in your reply, in Markdown, and put the result itself there: the text, the code, the table, the summary.
- Do not create files, folders or projects to hold an answer unless the user asks for a file.
- Use the workspace's files and tools when they help you answer, then give what you found in your reply.
- When the user does ask for files, say in your reply what you created and where.
