AI connectors

Workspaced does not provide its own AI models. Your assistant uses third-party models through OpenRouter, under those providers’ terms and privacy policies. Open Settings → AI connectors to add a named connection, then select it for a workspace. Your own provider usage is charged separately from workspace hosting. The protected Trial connector has a $1 lifetime budget with no automatic refill. Prompts and relevant context go to the selected providers; review their policies and check the assistant’s work.

Workspaces

A workspace is your own computer in the cloud. Its assistant can install software, edit files and run apps while you talk through chat. Sessions in the same workspace share its files and running services. Your apps can keep running when you close the browser. A free trial lasts four hours; when it expires, its machine, files and data are permanently deleted. Keep a copy of anything you need.

Recipes

A recipe is a reusable set of instructions for the assistant. In the Store, choose a public recipe or keep your own private ones; New recipe lets you write instructions or import Markdown. Read the steps and check the author before applying. Apply starts a session in the workspace you choose. For a first project, search for Simple web page by workspaced: it builds a welcoming demo page, asks you to confirm public access in chat, handles publishing, and gives you a link. You can then ask for any change in chat.

MCP servers

MCP (Model Context Protocol) lets the assistant use tools supplied by another service, such as searching connected information or working with an external app. Workspace Settings → MCP servers is where you configure those connections and review their state. Only connect services you trust, review their access, and keep credentials in Secrets. A recipe can help set up a connection; the service may need its own account or subscription.

Secrets

Secrets hold sensitive values such as passwords and API keys. Add them in workspace Settings → Secrets using the exact name your app or recipe needs. Saved values are hidden and become available to the assistant’s tools as environment variables after a restart. Never paste secret values into chat, public recipes or your page’s HTML. A restart applies the updated environment while keeping workspace files and conversations.

Variables

Variables are named settings for your apps, such as a preferred language or another non-sensitive option. Use workspace Settings → Variables to manage them, and Secrets for credentials. The workspace time zone is configured here too; the assistant uses it when interpreting your local times. Restart when the app indicates that changes need to be applied.

Sessions

A session is one conversation with the assistant. Start a new session for another piece of work or reopen an existing conversation to continue with its history. All sessions in a workspace share its files, so a change made in one can affect another. Workspace Settings → Sessions controls conversation retention; review it if you want to change how long inactive sessions are kept.

Firewall

A firewall decides which ports people can reach from outside the workspace. Starting a server does not automatically make it public. In Settings → Firewall, an open TCP port with From left empty allows anyone on the internet to reach the service listening there. The demo page uses port 80 and plain HTTP, which is unencrypted. Close a port when it is no longer needed. You can also let the assistant manage ports through chat using the permission on this screen. Keep private tools and credentials out of public pages.

Instructions

Instructions are lasting preferences and working notes shared across a workspace’s conversations. Use Settings → Instructions to save guidance you want the assistant to reuse, such as your writing style or how an app is operated. You can ask the assistant to maintain these notes through chat too. They guide its behaviour but should never contain passwords or API keys. You do not need to create any instructions to build the demo page.

Tasks

Tasks ask the assistant to do something later or on a recurring schedule while the workspace is running. Ask in chat, for example, “In 30 minutes, check my page” or “Every weekday at 9 am, write a summary.” Review, change or remove the prompt and schedule in Settings → Tasks, and see runs in Sessions. Runs use your AI connector’s budget. Tasks stop when their workspace is deleted; creating them is optional and is not part of the first-page tour.
