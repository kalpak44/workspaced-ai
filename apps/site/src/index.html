Everything your agent needs to get the job done

This isn't a sandbox that gets wiped when you leave. It's a real machine that keeps your project, your containers and your chats.

A machine per workspace

Each workspace gets its own cloud server. You pick the size, and nothing is shared with other users.

Chat with your agent

Run several chats in one workspace, use any model on OpenRouter, and tell the agent how you like to work.

A terminal in the browser

Jump in whenever you want. Your shells keep running after you close the tab.

Docker built in

The agent can build and run containers on its own machine, so what it makes really works.

Publish on your domain

Point your domain at it in a few clicks, and decide exactly which ports are open to the world.

Secrets, tools and recipes

Keep API keys safe as secrets, connect MCP servers, or start from a ready-made recipe.

How it works

  1. 1

    Top up your balance

    Add money by card, or turn on automatic top-ups. You'll see what each machine costs per hour before you start it.

  2. 2

    Create a workspace

    Pick a size and paste in your OpenRouter key. Your machine is usually ready in about a minute.

  3. 3

    Tell the agent what to build

    Chat with it, watch it work in the terminal, and publish the result once you're happy.
