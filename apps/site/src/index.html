Everything an agent needs to finish the job

Not a sandbox that forgets. A real machine that keeps your project, your containers and your conversations.

A machine per workspace

Each workspace runs on its own cloud VM. Pick the size; nothing is shared with anyone else.

Chat with your agent

Several sessions per workspace, any model on OpenRouter, and instructions that shape how it works.

A terminal in the browser

Step in whenever you like. Shells keep running when you close the tab.

Docker built in

The agent builds and runs containers on its machine, so what it makes actually runs.

Publish on your domain

Connect a domain in a few clicks and choose exactly which ports the firewall opens.

Secrets, tools and recipes

Store API keys as secrets, plug in MCP servers and start from ready-made recipes.

How it works

  1. 1

    Top up your balance

    Pay by card through Stripe, or let it top up automatically. You see the hourly price of every machine before you start it.

  2. 2

    Create a workspace

    Choose a size and paste your OpenRouter key. Your machine is ready in about a minute.

  3. 3

    Tell the agent what to build

    Chat, watch it work in the terminal, and publish the result when you are happy with it.
